# Anonymous NewInML 2026 Manuscript Scaffold

Projection-only manuscript package. Canonical evidence lives under `paper/newinml2026/` FCG.

## Build

```bash
./build.sh
```

Produces `main_smoke.pdf` (anonymous smoke test).

## Template

- Source: NeurIPS 2026 `Formatting_Instructions_For_NeurIPS_2026.zip`
- Mode: `\usepackage[dblblindworkshop]{neurips_2026}`
- Receipts: `TEMPLATE_SOURCE.json`, `BUILD_RECEIPT.json`

Do not add author names, affiliations, or deanonymizing URLs.
